# Hub Growth Tracker

A full-stack web application built with Django to track technical milestones during my ICT attachment at Swahilipot Hub, Mombasa, Kenya.

## Technologies Used
- Python & Django
- SQLite Database
- HTML, CSS, JavaScript
- Chart.js
- REST APIs
- Git & GitHub
- Deployed on Render

## Features
- User authentication (Login/Logout)
- Add, Edit, Delete milestones
- Milestone status tracking (Planned, In Progress, Completed)
- Category and Date filters
- Search bar
- Progress chart
- Export to PDF
- Profile page
- Social media links
